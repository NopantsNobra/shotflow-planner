# 瞬刻摄影工作台 · Stillmark

[English](README.en.md) · [功能与技术简介](overview.md) · [更新日志](CHANGELOG.md) · [产品总纲](PRODUCT.md) · [开发路线](docs/portable-agent-roadmap.md)

> 定格一瞬，刻下永恒。Freeze the moment. Leave a mark.

Stillmark 是一款 AI 友好的个人摄影策划与现场执行工作台：从一个灵感或一张图片开始，与常用 AI 协同形成摄影策划，再把同一份计划带到现场执行。项目、参考图、分镜、日程与清单集中在本地；可迁移的文件契约让外部 Agent 也能按明确任务方向生成可导入内容。多种 AI 的无缝集成是产品方向，当前外部 Agent 仍通过指南、文件和现有导入确认流程协作。

**以最低的策划成本获得最大的现场执行确定性，同时保留摄影师的创作自由。** 不要求预先决定曝光参数，不替代摄影师的审美判断，也不承担 RAW 管理、后期处理、复杂布光设计或大型制片管理。

- **v11.0.1**（当前）｜外部 Agent 对接补齐：机器可读 `capabilities.json`、包内 `packId`/`targetHint`、只读校验与 JSON 诊断、导入回执、英文契约文档、提示词指纹/导出、默认脱敏导出。
- **v11.0.0**｜提示词可审查、修改、复制与恢复，个人修改仅保存在本机。
- 本地保存、离线使用、PWA；项目和个人上传的图片不自动上传。
- [构建与测试状态](https://github.com/NopantsNobra/shotflow-planner/actions) · MIT License

## 设计哲学

**AI 友好 · 本地优先 · 原生可迁移**

- 本地优先：项目及个人图片由用户控制，核心工作流无需联网、账户或模型服务。
- 原生可迁移：以用户主动传输的资产包连接桌面、平板与手机，不依赖云同步。`main` 已包含严格脚本 CSP 与多项目、任意分镜 ZIP 导出/导入；分镜包可新建项目或追加至明确选择的项目，并兼容旧 JSON。
- 面向 Agent 开放：外部 Agent 可按[操作指南](docs/agent-guide.md)、[策划生成任务提示词](docs/agent-tasks/generate-shoot-plan-v3.md)、Schema 与 ZIP 示例生成资产，再经正常导入、预览和确认。设置页可逐字检查、修改和复制任务提示词；它不会自动调用模型或读取项目。可直接复制[独立盲测指令](docs/agent-blind-test-prompt.md)。ZIP 已通过三引擎 CI 与桌面浏览器复测；独立外部 Agent 盲测及真实手机/PWA 交接仍待发布后验收。

目标不是增加更多摄影管理功能，而是让人类和 Agent 都能以低摩擦方式组织、交接与执行摄影方案。详细范围及验收见 [开发路线](docs/portable-agent-roadmap.md)。

## 快速开始

**电脑**：下载 [shotflow.html](shotflow.html) 后用现代浏览器打开。无需安装程序。

**手机**：将 [shotflow-app/](shotflow-app/) 部署至 HTTPS 静态托管。iOS Safari 使用分享菜单「添加到主屏幕」；Android Chrome 使用「安装应用」或「添加到主屏幕」。首次联网加载完成后可离线使用。直接打开本地文件时不支持 Service Worker 或 PWA 安装；浏览器可能限制本地存储，请先确认保存可用。

## 工作方式

```text
概念 / 情绪板 / 参考图库 / 场景 / 清单
                  ↓
             分镜（中枢）
                  ↓
    日程 → 拍摄日模式 → 完成 / 补拍
       ↘ 客户提案 / 通告单 / 执行手册
```

同一份数据贯穿策划、沟通与现场执行，不必重复填写不同文档。

| 模块 | 用途 |
|---|---|
| 看板 | 六个项目阶段；搜索、进度、待办、归档 |
| 概念与情绪板 | 创作意图、文字、色彩与精选参考图；粘贴、拖放、多图导入、标签筛选 |
| 分镜 | 每条最多三张参考图；日期、场景、时长及可选机位/光线/备注；连续添加、复制、批量修改、拖拽及上下移动、必拍标记 |
| 日程 | 多日拍摄，线性排期，时间锁定，冲突提示，整体重排预览与撤销 |
| 清单 | 场景、服装道具、器材及完成状态；不维护复杂器材数据库 |
| 预算与协作 | 费用、支付状态、待办和沟通记录 |
| 拍摄日 | 深色全屏、当前事项、参考图大图、完成/跳过/稍后补拍、必拍提醒 |
| 文档 | 客户提案、独立 HTML 提案、通告单、执行手册，可打印或存 PDF |
| 收藏与素材包 | 跨项目引用；按需导出、追加导入并保留图片与场景依赖 |

### 策划模式

随拍、写真、专业与自定义模式共用一个项目数据结构。切换仅改变模块显隐，不删除数据。随拍优先保留概念、情绪板、分镜、清单与现场模式；写真增加日程与文档；专业模式显示完整工作台。自定义按需选择模块，分镜始终保留。

### 排程与自然光

分镜由时长与顺序派生时间，普通日内排期不会静默改变拍摄日期；排不下的分镜保留原日，整体重排经确认后才可跨日。锁定环节不自动顺延。日出、日落及黄金时段以拍摄坐标、目标日期和 IANA 时区近似计算；仅供参考，不计天气、遮挡及地形。

### 素材复用

情绪板只展示明确精选的图片；分镜上传的执行参考图默认进入项目参考图库，不自动混入提案。收藏可从其他项目引用。收藏素材包保留旧版 JSON 兼容；项目/分镜交接采用标准 ZIP，图片以独立二进制条目保存，分镜包可明确追加到指定项目。具体版本和容量边界见[资产包规范](docs/asset-pack-format.md)。请勿分享含客户隐私或无授权的素材。

## 数据、离线与隐私

项目与图片保存在浏览器 IndexedDB。不同标签页修改不同项目可事务合并；同项目冲突拒绝覆盖、保留会话草稿并提示备份。跨页通知需要浏览器支持 BroadcastChannel。项目备份以 JSON 迁移，无强制云同步。

- 单项目导出：项目页「导出此案」，导入为新项目。
- 整库备份：设置 → 数据与备份 → 导出备份；整库恢复需确认覆盖，导入先校验图片依赖并原子写入。
- 清除站点数据、卸载浏览器或设备故障可能导致本地数据丢失；换设备前请备份。
- 可选 shisei 姿势图库通过公共 CDN 同步，本地分页缓存；数据库 v4 将元数据与图片载荷分离，冷缩略图按数量、容量和闲置时间回收；普通备份不包含整个图库，外部引用可能需重新同步。素材包可打包已缓存的可迁移参考图。
- 主动提交反馈时，反馈内容与环境信息经 Web3Forms 发送；不自动收集项目内容。AI 仅有关闭的任务契约，不接入真实模型。

## 产品边界与剩余事项

不是大型影视排产、多人实时协作、合同收款、成片管理或后期编辑平台。日程采用轻量线性引擎，不做复杂资源约束求解。示例只读，可复制为自己的项目。严格脚本 CSP 与 ZIP 资产迁移均已合入 `main`；独立外部 Agent 和真实手机离线、升级与后台恢复验收仍待完成，存储分 key 等工程问题见 [backlog.md](docs/backlog.md)。AI 第 09 批暂停。
