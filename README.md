# 瞬刻摄影工作台 · Stillmark

> 定格一瞬，刻下永恒。

瞬刻摄影工作台，给独立摄影师和小团队用的轻量策划小工具。从情绪板上的一缕灵感，到分镜表里的每一格画面，再到提案与拍摄日程，最后走进实拍现场——把一瞬间，刻成永恒画面。零散想法、参考图和执行细节稳稳收在一处；小项目一个接一个，慢慢沉淀成属于你的策划档案。

---

## 一、核心架构

```
情绪板 / 场景 / 服化道 / 器材   →   分镜表（数据中枢）   →   客户提案
        （素材层）                  （一切挂载点）          执行手册
                                       ↓                  提案 HTML 文件
                                  拍摄日模式（含日程流程）
```

分镜表是整个应用的中枢：每条分镜可挂 1-3 张参考图（来自情绪板）、关联场景、带日期时段与预计时长。素材挂完，方案即成；现场执行、文档输出都从分镜表派生。

## 二、功能清单

### 1. 多项目看板（首页）
- 按生命周期分 5 列：灵感期 → 策划中 → 待拍摄 → 后期中 → 已交付
- 顶部统计条：进行中项目 / 今日拍摄 / 逾期待办 / 总预算
- 项目卡片显示客户、拍摄日倒计时（"还有 N 天"）、分镜进度条、待办数、逾期红标

### 2. 项目工作台（7 个页签，按 策划→执行→落地 分组）

| 分组 | 页签 | 说明 |
|------|------|------|
| 策划 | **概念** | 主题、调性、受众、用途、创意阐述，输入即自动保存 |
| 策划 | **情绪板** | 文字 / 色彩 / 图片素材，图片压缩 800px 存入 IndexedDB |
| 执行 | **分镜**（中枢） | 挂 1-3 张参考图 + 场景 + 日期时段 + 时长；拖拽排序；关键词搜索 |
| 执行 | **日程** | 拍摄日时间轴：流程节点（集合/化妆/转场/收工…）+ 当日分镜合并展示；**日出/黄金时刻/日落/暮光自动计算** |
| 执行 | **清单** | 场景选址 / 服化道 / 器材，可勾选 |
| 落地 | **预算** | 费用明细 + 总预算 / 已付 / 待付统计（支出红色） |
| 落地 | **协作** | 待办事项（负责人/截止日/逾期标红）+ 沟通记录（电话/微信/见面，时间倒序） |

### 3. 拍摄日模式（灵魂功能）🎬
- 深色全屏，日程节点与分镜按时间合并成一条流
- **自动高亮"当前该做什么"**，参考图随手看
- 52px 大按钮单手打勾，逾期一键「顺延 1 小时」
- 顶部显示当日日出 / 黄金时刻 / 日落 / 暮光时间，安排逆光、剪影镜头有依据
- 前一天 / 后一天快速切换

### 4. 三种文档输出
- **客户提案**（弹窗预览，可打印 / 存 PDF）
- **发送提案文件**：生成独立 HTML 文件（图片内嵌），微信直接发给客户
- **执行手册**：分镜 + 流程 + 场景 + 清单 + 待办 + 预算，打印带到现场

### 5. PWA 装到手机桌面
- 独立窗口、离线可用、镜头造型图标
- 版本更新时自动提示「发现新版本 → 刷新」

### 6. 数据安全
- 项目数据 localStorage（`wb_sf_` 前缀），图片 IndexedDB（库名 `shotflow`）
- 导出 JSON 备份含全部图片、导入完整恢复、清空二次确认、≥30 条备份提醒
- v3 自动迁移旧版数据（旧分镜的 refId 自动转为 refIds）

## 四、使用说明

### 本地打开
双击 `shotflow.html`。本地 `file://` 下 PWA 安装与 Service Worker 不可用（浏览器安全策略），其余功能全部正常。

### 手机安装（PWA）
把仓库中的 `shotflow-app/` 部署到任意静态托管（GitHub Pages、Netlify 等），用手机浏览器打开部署后的 HTTPS 地址。源码不含任何平台访问码；若所用平台要求 `sharecode` 一类访问参数，请在部署环节注入，不要写回仓库源码。

- **安卓 Chrome**：打开后点看板页「安装到桌面」，或菜单 →「添加到主屏幕」
- **iPhone Safari**：分享按钮 →「添加到主屏幕」
- 安装后离线可用；数据存手机本机，换设备前先「导出备份」

### 推荐使用流程
1. 看板页「+ 新建项目」
2. **概念**页签：主题 / 调性 / 受众 / 用途
3. **情绪板**页签：上传参考图、记文字灵感、取色
4. 项目信息卡填拍摄地点 + 经纬度（或点城市快捷键，如南京）→ 日程页就有日落时间
5. **分镜**页签：逐条添加，挂参考图 + 场景 + 时段，拖手柄排序
6. **日程**页签：加集合 / 化妆 / 转场 / 收工等流程节点
7. **清单**与**预算**页签补全
8. **协作**页签记待办和沟通要点
9. 「发送提案文件」发客户确认；「执行手册」打印带走
10. 拍摄当天进**拍摄日模式**，逐条打勾，逾期顺延
11. 交付后把项目状态拖到「已交付」

### 数据迁移
换设备前：看板页「导出备份」→ JSON 文件（含图片）；新设备「导入」恢复。

## 五、预置示例
首次打开内置「城市漫游者 · 人像写真」：4 条分镜（今日）、4 个流程节点、2 个场景、4 条素材、2 笔预算、2 条沟通记录、3 条待办。打开拍摄日模式即可看到当前时段高亮与日落时间条。

## 六、迭代记录
- **v1** `photo-planner.html`：六模块表单版
- **v2** `shotflow.html`：分镜中枢架构 + 多项目看板 + 拍摄日模式 + IndexedDB + PWA
- **v3**（当前）：新增日程时间轴、备注协作、多参考图、日落/黄金时刻计算、提案文件导出、看板统计、PWA 更新提示；旧数据自动迁移

## 七、已知限制
- 日落时间为 NOAA 近似算法 + 城市中心坐标估算，误差几分钟，仅作排期参考
- 本地 `file://` 打开时 Service Worker 不注册；PWA 安装需 HTTPS 或 localhost
- 任何平台访问码均不入库，需在部署侧配置
- 本地 `file://` 打开时无法安装 PWA
