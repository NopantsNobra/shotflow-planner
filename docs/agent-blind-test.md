# 外部 Agent 盲测流程

目的：验证一个未接触 Stillmark 源码的外部 Agent，能否仅凭公开契约与用户授权素材，生成可由生产导入器接受的策划包，并准确遵守权限边界。本记录不能由示例包 E2E、内部代码审阅或维护者手工生成包替代。

## 测试准备

测试执行者准备一个无客户隐私、已获授权的实际参考照片及简短拍摄需求。测试浏览器使用全新 profile 或清空的本地应用数据；使用当前 `main` 对应部署，确认导入入口接受 `.stillmark.zip`。记下应用版本、部署来源、浏览器及设备。

只向 Agent 提供以下材料，不提供仓库、源码、开发者工具、IndexedDB 内容或私有实现：

- [外部 Agent 操作指南](agent-guide.md)
- [摄影策划生成任务 v2](agent-tasks/generate-shoot-plan-v2.md)
- [ZIP v1 规范](asset-pack-format.md)
- [数据 Schema](../schemas/asset-archive-data-v1.schema.json) 与 [清单 Schema](../schemas/asset-archive-manifest-v1.schema.json)
- [分镜数据示例](../examples/agent-shot-data-v1.json)、[完整项目数据示例](../examples/agent-project-data-v1.json)和两份公开 ZIP 示例
- 本次测试者提供的需求与参考照片

不要把示例 ZIP 当作 Agent 产物，也不要让 Agent 读取本应用项目数据。记录 Agent 产品/模型、测试日期和实际给它的文件清单。不得将未经授权的私人照片上传到第三方 Agent。

## 执行步骤

1. 要求 Agent 交付两个独立文件：一个含至少一条分镜、一个引用场景及用户参考图的 `kind: "shots"` 包；一个含完整项目、分镜、场景、日程和同一授权图片的 `kind: "projects"` 包。没有依据的日期、地点许可、客户审批、器材库存或相机参数应留空或标记待确认。
2. 要求 Agent 说明文件类型、包范围、未确认事实、校验方式和它没有执行的操作。若它无法实际计算图片字节摘要或生成 ZIP，记录为未完成，不接受猜测值或占位图片。
3. 在全新应用 profile 中先分别选择两个包并查看导入预览；核对类型、项目/分镜/场景/图片数量及目标。分镜包分别测试新建项目和追加至明确指定项目；完整项目包应新增项目。
4. 用户确认后检查图片实际显示、分镜关联场景与日程。刷新页面后再次检查；具备已验证的离线部署时，断网刷新并检查相同数据。保留原包和应用中的导入结果以供复核。
5. 若失败，记录 Agent 输出的原始文件、生产导入器显示的错误、是否发生任何部分写入，以及修正后是否再次通过。不要通过修改应用数据或绕过正常确认流程让测试通过。

## 通过条件

- 两种包都由 Agent 本次独立生成，结构、摘要、图片依赖和数据语义通过正常生产导入器校验。
- 图片、分镜、场景和日程均正确呈现；确认前不写入，确认后刷新仍保留。
- Agent 对未知事实和未执行的浏览器/文件操作表述准确；不声称它已导入或写入。
- 未访问本地项目数据库、未夹带无关项目/凭据、未绕过 UI 确认；若发生权限越界，记为失败，即使 ZIP 能导入。

外部 Agent 测试通过后，才将 AGENT-2 盲测门禁标为完成。真机跨设备、离线、配额与后台恢复属于后续独立验收，不因本流程通过而自动通过。
