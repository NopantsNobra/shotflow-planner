# 后续事项

更新：2026-11-27。只列尚未完成且仍有验证价值的工作；已交付的功能见 [路线图](portable-agent-roadmap.md) 和 [更新日志](../CHANGELOG.md)。

## 发布后优先验证

- **独立 Agent 盲测**：不提供源码，分别生成并通过正常导入流程验证分镜包和完整项目包；核对图片、场景、日程、刷新持久化与失败恢复。
- **移动端迁移**：实测 iOS Safari、主屏幕 PWA、Android Chrome、离线刷新、更新和后台恢复。自动化浏览器测试不能替代真机结果。
- **Safari ZIP 导入识别**：Chrome 实机确认可导入；用户报告 Safari 提示“格式不正确”。代码中的“文件格式不正确，导入失败”文案来自旧 JSON 解析路径；若实际显示的是该提示，说明 ZIP 未进入归档解析流程。需记录具体 ZIP、文件名/扩展名、入口、应用/Safari 版本和完整提示，排查旧版 PWA 缓存及文件识别差异。两个包尚未分别完成 UI 预览/导入和刷新持久化记录；包级 Schema、摘要和引用闭包检查已通过。

## 工程与可用性

- 补旧/新客户端并存、清空与恢复并发交错的持久化回归。
- 验证真实指针拖拽、筛选后排序、跨日排程和异常中断的 UI 边界。
- 测试接近当前容量上限的真实设备表现；101.7 MB Chromium 压测已覆盖，128 MiB 边界与设备配额仍未知。
- 用真实屏幕阅读器检查看板键盘入口、参考图操作、选择/完成语义及图标按钮名称。
- 依据用户项目规模测量虚拟化需求；未有性能证据前不迁移 IndexedDB 的项目主存储结构。
- 对高纬度、夏令时和自定义地点校对日照近似值。

## 冻结项与配置项

- 内置 AI 模型调用保持关闭；重新启动需单独明确数据处理和产品授权边界。
- Web3Forms 的访问密钥目前可从客户端资源还原；域名限制和速率控制属于服务端账户配置。
- PoseWear 不在当前产品范围。全局标签词表、反馈 Markdown 导出和 Service Worker 运行时版本读取没有立项。
